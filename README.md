# Novel Reader for Android

A Kotlin and Jetpack Compose Android reader for legally downloadable, public-domain Chinese literature.

## Data source

The app searches [Gutendex](https://gutendex.com), an API for Project Gutenberg, and downloads plain-text editions only. It does not scrape or bypass paid services.

## Build

Open this repository in Android Studio. The project uses Gradle 8, Android Gradle Plugin 8.7, Kotlin 2.0, and Compose.

## Features

- Search Chinese-language public-domain books
- Download plain text for offline reading
- Maintain a local bookshelf
- Read downloaded books inside the app
